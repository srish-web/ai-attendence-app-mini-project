# ai-attendance-project-app

**A Third-Year Mini Project | Computer Science & Engineering**

SnapClass is an AI-powered attendance management application designed to make the attendance process faster, smarter, and more convenient. It provides a digital platform for teachers and students, integrating automated attendance-related functionalities with an interactive application interface.

## About the Project

SnapClass was developed as a **third-year academic mini project** by a team of three members.

The project focuses on exploring how Artificial Intelligence and Python-based technologies can improve traditional attendance management systems by reducing manual effort and providing a more efficient digital experience.

## Key Features

- **Teacher Dashboard:** Dedicated interface for teachers to manage attendance-related activities.
- **Student Dashboard:** Student-specific interface for accessing the application.
- **AI-Based Recognition:** Integration of face recognition and related AI processing libraries.
- **Digital Enrollment:** Student enrollment through unique join codes.
- **Database Integration:** Supabase integration for data management.
- **Secure Authentication:** Password hashing and authentication-related functionality.
- **QR Code Support:** QR code generation for enrollment and related workflows.

## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/srish-web/ai-attendence-app-mini-project.git
```

### 2. Navigate to the Project Directory

```bash
cd ai-attendence-app-mini-project
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Application

```bash
streamlit run app.py
```

Configure the required database credentials and dependencies before running the application.
